# Dance_web_App
# 쿠폰 카드 (Dance_web_App)

횟수제 쿠폰을 쓰는 학원·센터 회원을 위한 개인 쿠폰 장부이다. 회원 바코드를 폰 화면에 띄우고, 사용할 때마다 남은 횟수를 하나씩 줄인다.

## 바로 쓰기

폰 브라우저(크롬, 사파리)로 아래 주소를 연다. 설치는 필요 없다.

https://lightswish.github.io/Dance_web_App/

브라우저 메뉴에서 "홈 화면에 추가"를 누르면 앱처럼 아이콘이 생긴다.

## 기능

- 회원 바코드 표시 (CODE128, CODE39, EAN-13, EAN-8, ITF, Codabar)
- 쿠폰 등록: 구입 횟수, 구입한 날, 사용 기간(1·2·3개월, 기한 없음)
- 전체 횟수 중 남은 횟수와 남은 사용 기간 표시
- 1회 사용, 방금 사용 취소, 날짜별 기록
- 강제로 맞추기: 학원 기록과 다를 때 횟수와 기간을 직접 수정
- 스캐너 불빛 자동 감지(시험 기능): 전면 카메라로 스캐너의 붉은 불빛을 감지해 자동 차감

## 알아 둘 점

- 기록은 각자의 폰 브라우저에만 저장된다. 서버로 보내지 않는다. 브라우저 데이터를 지우거나 폰을 바꾸면 기록이 사라지므로, 그때는 "강제로 맞추기"로 다시 넣는다.
- 카메라 영상은 폰 안에서 색과 밝기만 계산하며 저장하거나 전송하지 않는다.
- 공식 기록은 학원 컴퓨터이다. 이 앱의 숫자는 개인 장부이므로 가끔 학원 기록과 맞춰 본다.
- 불빛 자동 감지는 스캐너 종류에 따라 되지 않을 수 있다. 처음에는 시험 모드로 확인한다.
